## Imagery
Imagery not needed: games are rendered with CSS/canvas/SVG (cards, roulette wheel, mines grid, crash curve, plinko pegs) for zero-buffering lightweight play; lobby uses typographic game tiles with suit/symbol glyphs, no stock photos, no generated fake casino photos.

## Long-term data behavior
- **Refresh policy**: No scheduled refresh. Wallet, bets, requests update on user action via invalidateQueries. Sportsbook stays demo until admin adds API keys.
- **Growth**: One wallet row per demo user (single-user artifact: player + admin views of same DB), append-only ledger, bets, deposit/withdraw requests, tenants. Seeded once via post-submit populate if empty.
- **Ordering**: Bets and ledger newest first; lobby games in fixed curated order with Crash featured.
- **Time semantics**: All timestamps are creation instants stored as ms, rendered viewer-local. No event-time fixtures claimed as live.
